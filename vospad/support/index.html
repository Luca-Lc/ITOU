Connect your iPhone

  1. Install and open the receiver

    Download the Windows package above, follow its installation instructions, and keep the receiver running. If prompted, install its required virtual-controller driver so games can recognize the controller.

  2. Use the same local network

    Connect iPhone and PC to the same local network. The PC may use Ethernet or Wi-Fi. Allow the receiver through Windows Firewall on a trusted private network; you do not need to turn off the firewall.

  3. Scan and confirm your computer

    Show a fresh pairing QR code in the Windows receiver. In VosPad, start connecting from Home, scan the code, and confirm the computer name. If the code has expired or was already used, refresh it in the receiver.

  4. Choose a template and play

    Choose a controller template, enter the controller and rotate iPhone to landscape. Open your game on the PC and select controller input if the game requires it. Game and driver support determine which features are available.

Common questions

Connection times out or the PC cannot be found

Keep the receiver open and check the PC's selected network address. Both devices must be on the same reachable local network; guest Wi-Fi, access-point isolation, a VPN or firewall rules may block the connection. Check VosPad's Local Network permission in iPhone Settings. Refresh the QR code if the PC's address changed.

Connected, but the game does not respond

Check whether inputs appear in the receiver's input monitor. If they do, check its virtual-controller driver status, controller slot and the game's controller settings. Diagnostic mode can display input without creating a controller for games. VosPad does not guarantee support for every game.

Can I customize the controller?

Open Templates to use a built-in design or edit a DIY template. Drag components, resize them, replace their appearance or add a background. Save the result to My Templates; templates you create can also be deleted.

How do I open the in-game menu?

Use the handle at the screen edge and swipe inward to open the menu. The menu provides connection actions, template selection and a way to leave the controller. Input is released while the controller is inactive, disconnected or in the background.

Haptics or motion controls are unavailable

Check Settings → Controller Experience in the app, the iPhone's system permissions and hardware support. Game-driven vibration also requires support from the Windows receiver, virtual controller and game. Motion controls must be enabled and used while the landscape controller is active.

How do I delete data or withdraw consent?

Delete custom templates in Templates, forget computers under Settings → My Computers, and revoke devices in the Windows receiver. Under Settings → Terms and privacy, choose Withdraw consent. This stops connections and input until you agree again; it does not automatically erase previously stored data. Manage system permissions separately in iPhone Settings.

连接你的 iPhone

  1. 安装并打开接收端

    下载上方 Windows 安装包，按包内说明完成安装并打开接收端。如提示需要虚拟手柄驱动，请按接收端说明安装，供游戏识别手柄。

  2. 连接同一局域网

    将 iPhone 与电脑接入同一局域网，电脑可使用有线网络或 Wi-Fi。在可信的专用网络中允许接收端通过 Windows 防火墙，无需关闭防火墙。

  3. 扫码并确认电脑

    在 Windows 接收端显示新的配对二维码，从 VosPad 首页发起连接，扫码并确认电脑名称。如二维码已过期或已使用，请在电脑端刷新。

  4. 选择模板并进入手柄

    选择喜欢的手柄模板，进入手柄后横置 iPhone。在电脑上打开游戏；如游戏需要，请在游戏设置中选择手柄输入。功能可用性取决于游戏和驱动支持。

常见问题

连接超时或找不到电脑

确认接收端已打开，检查电脑端选择的网络地址。两台设备需要位于可相互访问的局域网；访客 Wi-Fi、无线隔离、VPN 或防火墙规则可能阻止连接。请在 iPhone 系统设置中检查 VosPad 的局域网权限；电脑地址变化后需刷新二维码。

已连接，但游戏没有反应

先检查接收端的输入监视是否响应。如能看到输入，请继续检查虚拟手柄驱动状态、手柄席位及游戏的手柄设置。诊断模式可显示输入，但不会为游戏创建手柄。VosPad 不保证与所有游戏兼容。

可以自定义手柄吗？

在“模板”页选择内置样式，或进入 DIY 编辑。可手动拖动组件、调整大小、替换样式并设置自选背景。保存后可在“我的模板”中使用，也可以删除自己创建的模板。

如何打开游戏中的菜单？

通过屏幕边缘的菜单把手向内滑动展开菜单，可处理连接、切换模板或退出手柄。手柄失去活动状态、断开连接或 App 进入后台时会释放输入。

震动或体感不可用

检查 App“设置 → 手柄体验”、iPhone 系统权限及设备硬件支持。游戏震动还需 Windows 接收端、虚拟手柄及游戏支持。体感功能需要先启用，并在横屏手柄处于活动状态时使用。

如何删除数据或撤回同意？

可在模板页删除自定义模板，在“设置 → 我的电脑”忘记电脑，并在 Windows 接收端撤销设备授权。在“设置 → 协议与隐私”中选择“撤回同意”，会停止连接和输入，重新同意后可恢复；撤回不会自动清除已保存的数据。系统权限需在 iPhone 设置中单独管理。
